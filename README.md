# Darwix Assignment

This repository contains the solutions for the Darwix assignment.

The currently implemented solutions are kept as separate projects inside their own folders.

## Structure

```text
darwix-assignment/
│
├── q1_voice-agent/
│   └── README.md
│
└── q2_knowledge-base/
    └── README.md
```

Each folder contains the complete solution for that question.

Every question also has its **own README.md** with:

* Setup instructions
* How to run the solution
* How to use/test it
* Project structure
* Important implementation details
* Current limitations

Please refer to the README inside each question's folder for the relevant setup and usage instructions.
